## 👨‍💻 Profile & Research Interests

- 🎓 **Academic Background:** Undergraduate Scholar in Bachelor of Data Science (BDS) at the **School of Mathematical Sciences, Tribhuvan University**.
- 🎯 **Target Direction:** **Erasmus Mundus Joint Master (EMJM)** in Data Science, Artificial Intelligence, and Biostatistics / Quantitative Epidemiology.
- 🔬 **Core Focus:**
  - **Financial Econometrics & Time-Series:** Microstructure analysis of emerging stock markets (NEPSE), speculative event studies, and volatility modeling.
  - **Clinical Biostatistics & ML:** Supervised predictive classification for patient therapeutic response using inflammatory biomarkers (CRP, ESR).
  - **DataOps & Reproducibility:** Automated data extraction via scheduled GitHub Actions cron workflows, continuous validation, and reproducible environments.
- ⚙️ **Operating Environment:** Fedora Linux, Git, Python 3.12, VS Code, Bash.
